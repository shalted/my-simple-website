02 / KNOWLEDGE CONSTELLATION

六条彼此相连的学习路径

分类不是孤岛。数据结构支撑算法，算法塑造游戏逻辑，工程设计让它们稳定运行。

NODE 01

算法

A* 寻路、GJK、空间划分、碰撞检测与集群 AI。

NODE 02

游戏 AI

状态机、行为树、效用 AI、GOAP、RVO 与 ORCA。

NODE 03

工程设计

对象池、事件系统、资源生命周期与泛型消重。

NODE 04

逻辑模式

冷却、计时器、Tick、随机系统、Flags 与脏标记。

NODE 05

数据结构

从二叉堆和优先队列，理解数据如何影响运行效率。

NODE 06

C# 集合

List、Dictionary、HashSet、Queue 与 Stack 的使用边界。

03 / LEARNING ROADMAP

不是收藏知识，而是建立连接

从基础容器到复杂决策模型，每一步都能回到前面的知识节点，并形成可复用的工程判断。

01 · 结构与容器

掌握集合、堆、树与空间索引。

02 · 算法与模拟

用可视化理解寻路、碰撞和群体运动。

03 · 决策与架构

连接 AI 建模、事件系统和资源生命周期。
