# 算法

这个分类用于沉淀算法与逻辑决策相关的知识：排序、搜索、贪心、动态规划、启发式评分、调度策略、路径规划、状态更新和游戏 AI 决策。

## 先建立总模型

算法学习先看输入规模怎样缩小、维护什么不变量、结果是否保证最优。空间划分和 Broad Phase 缩小候选，BFS、Dijkstra 与 A 星选择扩展顺序，GJK、SAT 和 CCD 回答几何关系。

### 一条典型查询链

```text
场景对象：10,000
空间划分候选：约 40
规则过滤后：12
精确形状判断后：3
对 3 个结果再按分数、距离或路径成本排序
```

## 推荐顺序

1. BFS、DFS、Dijkstra 与 A 星，理解搜索顺序和累计成本。
2. 九宫格、四叉树和目标筛选，理解候选缩减。
3. Broad Phase、SAT、GJK 和 CCD，理解离散与连续几何。
4. 启发式打分、槽位分配和算法工具箱，连接到玩法决策。
