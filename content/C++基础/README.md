# C++ 基础

这个分类用于建立 C++ 对象、资源与值类别的统一心智模型，从动态绑定进入所有权，再连接到移动语义和任务队列。

## 先建立总模型

C++ 这组内容围绕“对象现在是什么类型、谁拥有资源、责任怎样转移”展开。动态绑定决定调用哪个实现，RAII 决定何时释放，移动语义决定怎样转交而不重复复制资源。

### 一份资源的完整路线

```text
派生对象 Warrior 通过 Character* 调用虚函数
对象持有 1 MiB 缓冲区，由 unique_ptr 独占
任务入队时移动所有权，不复制 1 MiB 数据
消费者处理完成，RAII 在作用域结束时释放
```

## 推荐顺序

1. 对象模型与动态绑定。
2. RAII 与智能指针。
3. 左右值、移动语义与任务队列。
