# 知识专题路线

这份路线把游戏开发相关知识按主题和依赖关系组织起来，便于从基础概念逐步进入算法、AI 与工程设计。

## 核心专题地图

### 1. 位标记 Flags / BitMask

建议分类：游戏逻辑常用模式 / CSharp 基础数据结构

核心内容：

- 用一个 `int` 或 `enum flags` 表示多个开关。
- 按位或 `|` 添加标记。
- 按位与 `&` 判断标记。
- 按位取反 `~` 移除标记。
- 适合表示 `CanMove`、`CanAttack`、`Invincible`、`Stunned`、`Silenced`、`Selectable` 等状态。

重点问题：

- 为什么不用很多 `bool`？
- Flags 怎么声明？
- 如何添加、移除、判断多个状态？
- 位标记适合什么，不适合什么？

### 2. 随机系统

建议分类：游戏逻辑常用模式 / 算法

核心内容：

- 普通随机。
- 稳定随机。
- 加权随机。
- 保底随机。
- 洗牌袋随机。

重点问题：

- 为什么纯随机有时体验不好？
- 加权随机怎么写？
- 保底机制怎么避免玩家长期倒霉？
- 洗牌袋如何保证“随机但不极端”？

### 3. 空间划分

建议分类：算法 / 游戏逻辑常用模式

核心内容：

- 为什么范围查找不能每次遍历所有单位。
- 网格 / 九宫格查找。
- 四叉树思想。
- 空间 Hash。

重点问题：

- 怎么快速找到附近敌人？
- 为什么先粗筛再精筛？
- 距离平方比较为什么比开根号更常用？

### 4. 对象生命周期状态

建议分类：工程设计 / 游戏逻辑常用模式

核心内容：

- 用状态控制对象生命周期。
- 常见状态：`Created -> Active -> Releasing -> Released`。
- 防止重复初始化、重复释放、异步回调打到已销毁对象。

重点问题：

- 为什么对象销毁前要有 `Releasing` 状态？
- 异步加载回来时对象已经关闭怎么办？
- 生命周期状态和资源释放有什么关系？

### 5. 缓存与失效策略

建议分类：工程设计

核心内容：

- 缓存什么时候建立。
- 缓存什么时候读取。
- 缓存什么时候清理。
- 缓存什么时候过期或重建。
- 和脏标记 Dirty Flag 的关系。

重点问题：

- 缓存为什么容易造成旧数据？
- 什么是缓存失效？
- 怎么用版本号管理缓存？
- 怎么区分短期缓存、长期缓存、全局缓存？

### 6. 命令模式 Command

建议分类：工程设计 / 游戏AI与逻辑建模

核心内容：

- 把“要做的事”包装成对象。
- 适合技能指令、AI 指令、撤销操作、网络同步。

重点问题：

- 为什么要把操作封成命令？
- 命令如何排队执行？
- 命令如何支持撤销？
- 命令和事件有什么区别？

### 7. 事件系统进阶

建议分类：工程设计

核心内容：

- 事件队列。
- 延迟事件。
- 一次性监听。
- 事件调试。
- 事件风暴。

重点问题：

- 为什么事件过多会让流程变隐形？
- 事件是否应该立即执行？
- 怎么避免重复订阅？
- 怎么定位谁监听了事件？

### 8. 数据驱动

建议分类：工程设计 / 游戏逻辑常用模式

核心内容：

- 用配置表驱动行为，而不是把规则写死在代码里。
- 技能、怪物、掉落、关卡、Buff 都可以数据驱动。

重点问题：

- 数据驱动和硬编码的区别。
- 配置表字段如何映射到运行时行为。
- 怎么避免配置变成另一种代码地狱？
- 什么时候该配置，什么时候该写代码？

### 9. 优先级系统

建议分类：算法 / 游戏逻辑常用模式

核心内容：

- UI 提示优先级。
- 技能优先级。
- AI 行为优先级。
- 任务优先级。
- 和堆、启发式评分模型的关系。

重点问题：

- 优先级和评分有什么区别？
- 固定优先级什么时候够用？
- 多因素评分什么时候更合适？
- 如何避免低优先级永远没有机会？

### 10. 有限资源调度

建议分类：算法 / 工程设计

核心内容：

- 怪物攻击令牌。
- 下载并发数。
- 特效播放上限。
- 线程池。
- 请求限流。

重点问题：

- 什么是令牌？
- 为什么不能所有请求同时执行？
- 如何分配有限名额？
- 如何处理等待队列和公平性？

## 专题学习路线

这些主题按知识依赖关系拆成可以持续讲解的模块，后续知识专题可以从中选择内容继续扩展。

### 1. 寻路与导航系统

建议分类：算法 / 游戏 AI 与逻辑建模

核心问题：

- NavMesh 的网格烘焙，以及具体寻路算法流程。
- 寻路的时候怎么做可跳跃点 / 断点。
- A Star 寻路具体流程。
- 刷怪选点时，如果点位刚好在柱子、障碍物附近，怎么规避。
- 群体靠近战斗时，一群怪物围绕角色的协同逻辑是什么。

建议拆成专题：

- NavMesh 是什么，和 A Star 是什么关系。
- NavMesh 烘焙出来的数据长什么样。
- A Star 在网格地图和 NavMesh 多边形上的区别。
- 动态障碍、不可达点、出生点合法性检测。
- 群体站位、槽位分配和空间划分的关系。

### 2. 局部避障与群体移动

建议分类：算法 / 游戏 AI 与逻辑建模

核心问题：

- RVO2 避障具体流程。
- RVO 和 ORCA 的区别。
- 多个单位同时移动时如何避免互相挤住。

建议拆成专题：

- Steering、RVO、ORCA 分别解决什么问题。
- 期望速度、障碍速度、可选速度空间。
- 局部避障和全局寻路的分工。
- 群体移动里为什么不能只靠 NavMesh。

### 3. 物理碰撞与空间加速

建议分类：算法 / 数据结构 / 游戏逻辑常用模式

核心问题：

- 物理引擎宽阶段、窄阶段判定流程。
- BVH 是什么。
- AABB、OBB、任意多边形碰撞检测。
- SAT 算法具体流程。
- GJK 算法具体流程。
- CCD 是什么、怎么做。

建议拆成专题：

- 碰撞检测为什么要分 Broad Phase 和 Narrow Phase。
- AABB、OBB、圆、胶囊体的适用场景。
- BVH、四叉树、空间 Hash 的区别。
- SAT 如何用投影轴判断分离。
- GJK 如何用闵可夫斯基差和单纯形判断碰撞。
- CCD 如何处理高速物体穿透问题。

### 4. 动作游戏战斗判定

建议分类：游戏逻辑常用模式 / 工程设计

核心问题：

- 动作游戏伤害判定怎么做。
- 受伤、无敌、反击、霸体这些状态怎么互相影响。
- 判定盒、受击盒、攻击者和受击者的职责怎么划分。
- 动画、特效、UI 反馈如何和战斗判定连接。

建议拆成专题：

- 攻击判定盒和受击判定盒。
- 伤害流程：命中检测 -> 防御/无敌/霸体判断 -> 伤害结算 -> 反馈播放。
- 动画事件驱动判定和逻辑帧驱动判定的区别。
- 战斗状态优先级：无敌、霸体、硬直、打断、反击。
- 谁负责产生伤害，谁负责承受伤害。

### 5. Buff 与 GAS 思路

建议分类：工程设计 / 游戏逻辑常用模式

核心问题：

- 一个通用 Buff 系统如何设计。
- Buff 怎么影响美术表现。
- Buff、特效、UI 反馈如何联动。
- GAS 类系统里属性、效果、技能之间如何拆分。

建议拆成专题：

- Buff 的生命周期：添加、刷新、叠层、过期、移除。
- Buff 影响属性、行为、表现的三条线。
- Buff 和事件系统、属性系统、技能系统的边界。
- 免疫、驱散、叠层、互斥、优先级。
- 用 GAS 思路理解 Ability、Effect、Attribute。

### 6. UE 与 Gameplay 框架

建议分类：工程设计 / 游戏 AI 与逻辑建模

核心问题：

- UE 的 Gameplay 框架是什么样的。
- 游戏 AI 了解多少：行为树、目标导向行为规划、层次任务网络、蒙特卡洛树搜索。
- ECS 怎么做。
- 对话系统表结构怎么设计。

建议拆成专题：

- UE 里的 GameMode、GameState、PlayerController、Pawn、Actor、Component。
- 行为树、GOAP、HTN、MCTS 分别适合什么决策问题。
- ECS 的 Entity、Component、System 思想。
- 对话系统的数据表：节点、选项、条件、效果、跳转。

### 7. C++ 与底层基础

建议分类：C++ 基础 / 计算机基础

核心问题：

- 引用和指针。
- 数组和链表。
- 多态、虚函数底层原理。
- 构造函数和析构函数。
- 智能指针。
- 左值、右值。
- 进程和线程。
- 多线程用得多不多，实际用在哪里。
- 数组内原地构建最小堆。

建议拆成专题：

- C++ 对象模型：虚表、虚指针、动态绑定。
- RAII、构造析构、资源所有权。
- `unique_ptr`、`shared_ptr`、`weak_ptr` 的区别。
- 左值引用、右值引用、移动语义。
- 线程、锁、任务队列、生产者消费者。
- 堆结构和原地建堆流程。

### 8. 内存、并发与平台基础

建议分类：计算机基础 / 工程设计

核心问题：

- Linux 底层原理。
- malloc 申请内存空间的底层流程。
- shared_ptr 线程安全问题。
- 原子变量底层如何做到内存屏障。
- 注入、内存屏障等底层概念。

建议拆成专题：

- 虚拟内存、页、堆、栈。
- malloc/free 和操作系统内存分配的关系。
- 原子操作、可见性、有序性、内存屏障。
- shared_ptr 的引用计数线程安全和对象访问线程安全。
- 进程、线程、上下文切换。
