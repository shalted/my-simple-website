# CSharp 语言基础

这个分类用于系统整理 C# 语言本身的核心语义，关注类型、职责边界、可变性、空值与成员声明，而不只停留在集合 API 的使用。

## 先建立总模型

C# 语言基础主要回答两层问题：一个值是什么、能否为空、可以通过什么契约调用；以及一个成员属于实例还是类型、允许在什么时候改变。先理解语义，再记关键字会更稳定。

### 一组贯穿数据

```text
Player Id=42：构造后不变
Speed=5：实例自己的可变属性
AliveCount=3：所有 Player 共享的 static 状态
IDamageable.TakeDamage(25)：接口契约
Target=null：契约正确，但当前没有可调用对象
```

## 推荐顺序

1. 先读类型、接口、委托与空值，建立“值、能力、行为和缺失状态”的边界。
2. 再读属性、常量、静态与只读，判断数据由谁拥有以及何时允许修改。
