# 游戏逻辑常用模式

这个分类用于沉淀游戏逻辑里高频出现的小模式：时间控制、冷却、Tick、脏标记、位标记、延迟触发、节流、防连点、重试间隔等。

## 先建立总模型

这些小模式都在控制“什么时候更新、哪些状态需要记住、重复工作怎样合并”。冷却和 Tick 管时间，Dirty Flag 管延迟计算，Flags 管多个真假状态，随机系统管不确定结果的分布。

### 同一帧里的状态

```text
技能冷却剩余：3.0 秒
Attack 在本帧被修改 3 次：只标脏一次，帧末重算
角色 Flags：Poisoned + Stunned = 0011
掉落权重：金币 50、药水 30、武器 20
```

## 推荐顺序

1. 时间控制模式。
2. 普通 Dirty Flag，再进入属性局部重算。
3. Flags 与随机系统。
