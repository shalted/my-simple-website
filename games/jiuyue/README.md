# 神仙摸鱼棋：模块导航

2026-09-16 按功能拆分。开发入口仍为 index.html；整个目录保留时可离线打开。现在不再把 index.html 单独复制作为完整游戏。

## 文件职责

| 文件 | 职责 / 主要入口 |
| --- | --- |
| index.html | 页面结构、显式样式和脚本引用；不内嵌业务或 Base64 |
| styles.css | 页面、棋盘容器、商店、档案和羁绊小条样式 |
| js/enemies.js | 四种敌方身份、动作键和 enemyWave；独立于英雄商店，导出 LionEnemies |
| js/characters.js | STATS、CHARACTERS、character；数值、身份、神话介绍、动作映射；导出 LionCharacters |
| js/equipment.js | 装备配置、resolveEquipmentBonuses、resolveBaseStats；导出 LionEquipment |
| js/synergies.js | SYNERGIES、synergyState、synergyBonuses、说明格式化；导出 LionSynergies |
| js/skills.js | 六名角色的主动技能、能量规则、杨戬直线判定与三星虾兵配置；导出 LionSkills |
| js/engine.js | createUnit、Game、寻路、占格、动作时钟、弹道、伤害和最终属性结算；导出 LionChess |
| js/campaign.js | Campaign；商店、金币、人口、备战席、合成、装备流转、关卡与奖励；导出 LionCampaign |
| js/renderer.js | Canvas 棋盘、角色帧、血条、弹道与特效；导出 ChessRenderer |
| js/ui.js | DOM 交互、输入、羁绊提示、档案、伤害榜、页面主循环 |
| js/assets.js | 生成的 Base64 素材清单，不手动编辑 |
| art/ | 美术源图、透明图集和验收清单；部署仍通过 assets.js 使用素材 |

加载顺序：assets → enemies → characters → equipment → synergies → skills → engine → campaign → renderer → ui。采用经典脚本和独立 IIFE，不新增打包器或运行依赖，不新增缺模块兼容回退；必需模块缺失应明确暴露错误。

战斗中普攻命中使攻击者获得 20 能量，任何承伤使受击者获得 10 能量；满 100 后在当前动作结束时自动施放。九月发射三团狐火，杨戬射出贯穿直线的天眼金光，烈烈召唤可独立承伤与死亡的虾兵，哪吒刷新三头六臂强化，小玉保护生命比例最低的友军，哮天贴身咬击。技能使用最终战斗属性；装备爆击与吸血通过统一伤害入口作用于普攻和伤害型技能，不新增法强或独立技能伤害词条。

## 并行修改边界

- 羁绊/角色内容：优先 js/synergies.js、js/characters.js。
- 装备：优先 js/equipment.js；背包及奖励在 campaign.js，装备交互在 ui.js。
- 主动技能：独立配置/规则模块优先；需要动作状态时与装备任务串行修改 engine.js。
- 美术：art/ 可独立制作；统一通过素材构建进入 assets.js。
- engine.js、campaign.js、ui.js 仍可能有交叉点，改共享函数前协调，不执行旧版整 HTML 替换脚本。

装备采用击杀掉落：每只被击杀的小怪独立以 15% 概率掉落一件，不再三选一或每回合保底。当前包含哪吒、杨戬、玉兔、敖烈、九尾狐、哮天犬、齐天大圣共 7 套、21 件神话装备；所有角色均可穿戴，每人 3 格，集齐同套三个不同部件才激活并显示套装加成，重复件只提供单件属性。
装备与套装可提供生命、攻击、护甲、攻速、移速、爆击和吸血。爆击统一按 1.5 倍伤害结算；吸血取实际生命伤害，不计算被护盾吸收的部分，也不会超过最大生命或让已阵亡角色复活。
